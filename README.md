# Clatix Client - Fabric 1.21.1

Advanced utility mod for Minecraft 1.21.1 with Fabric.

## Features
- Combat: KillAura, CrystalAura, AutoCrystal, Criticals, AutoTrap, Surround
- Movement: Sprint, Speed, Flight, Step, NoFall, Jesus, Scaffold
- Render: ESP, Fullbright, Chams, Tracers, Nametags, ViewModel
- Player: AutoEat, AutoLog, AutoReconnect, AntiHunger
- Exploit: BookDupe, ChunkBan, Coordinates
- Click GUI with draggable panels
- Keybind system
